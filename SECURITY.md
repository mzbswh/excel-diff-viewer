# Security Policy

## Supported versions

Security fixes are provided for the latest Marketplace release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository when it is available. If private reporting is not enabled, open a minimal issue that does not include exploit details, credentials, confidential workbooks, or other sensitive information, and request a private contact channel.

Please include the affected version, impact, reproduction conditions, and any suggested mitigation. Allow reasonable time for investigation before public disclosure.
